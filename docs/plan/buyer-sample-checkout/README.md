# buyer-sample-checkout — 바이어 제품 샘플 주문 (KLOW 직접 조달 · KLOW 송장)

바이어 공간 제품 상세에서 **"Get N samples"** 로 한 제품의 샘플을 어드민이 정한 개수·단가 그대로 결제한다.
KLOW 운영팀이 그 제품을 올리브영 등에서 **직접 사서** 포장해 바이어 주소로 보내고, 어드민 **바이어 주문** 탭에서
**KLOW 송장**(발송인 KLOW)을 발급한다. 그 EFS 배송비는 **KLOW 부담**이다 — 어느 브랜드에게도 청구하지 않는다.

```
바이어(로그인) 제품 상세 → [Get 10 samples] → 배송지 입력 → 엑심베이 USD 결제
  총액 = 샘플 단가 × 샘플 개수 + 목적국 7kg 배송비(SeedingRate)
  → 어드민 주문 목록에 유형 '바이어주문' · 어드민 '바이어 주문' 탭(목록·상세)
  → 운영팀이 올리브영 등에서 구매·포장 (시스템 밖)
  → 상세에서 'KLOW 송장 발급' = EFS 송장 1장, 발송인 KLOW(ShopSettings.klowSender*), Shipment.brandId NULL
  → EFS 정산표 업로드: 매칭되지만 'KLOW 부담' 으로 분리 — 미매칭 아님 · 브랜드 청구서에 안 들어감
```

> 2026-10-29 에 지운 $100 샘플 박스·합포장 송장([결정 storefront 2026-10-29](../../decisions/storefront.md#2026-10-29))과
> 겉모양이 닮았지만 **브랜드 입고 흐름이 없다**(브랜드는 이 주문을 모른다). 송장·청구 부분은 지운 코드
> klow_server `1b89c2b`(KLOW 합포장 송장 · `Shipment.brandId` NULL)·`4e580c4`(efs-billing `klowSamples`)를
> git 에서 참고해 다시 세운다. 지운 아카이브 [`archive/buyer-sample-order/`](../../archive/buyer-sample-order/README.md).

## 결정 (2026-11-02 사용자)

| # | 결정 |
|---|---|
| D1 | 결제 = **엑심베이 카드결제(USD)**. 결제가 끝나야 주문이 접수된다(`paid` 전 주문은 어드민 탭에 '결제 대기'로만) |
| D2 | 대상 = **인디(`BuyerProduct`) + 메이저(`BuyerMajorProduct`) 둘 다**. 어드민 제품 편집에 **샘플 개수 · 샘플 단가(USD)** 두 칸. 둘 다 있어야 버튼이 뜬다 |
| D3 | 바이어는 **어드민이 정한 개수·단가 그대로** 결제한다 — 수량 조절 없음. 버튼 문구가 개수를 그대로 쓴다("Get 10 samples") |
| D4 | 인디 구간표 **1행 = 샘플가** 규칙은 새 샘플 칸으로 **대체**한다(PDP 샘플 표시는 새 칸에서) |
| D5 | 배송비 = **목적국 `SeedingRate` 7,000g 티어 값 1회**(개수 무관) — 원→USD 환산은 소비자 주문과 같은 방식. 7kg 티어가 없는 국가는 주문 불가 |
| D6 | 주문 자격 = **로그인한 바이어 전부**(검수 대기 포함). 비로그인은 버튼 → 로그인 모달 |
| D7 | 송장 = 어드민 '바이어 주문' 상세의 **'KLOW 송장 발급'** — 발송인 KLOW, 브랜드 없음 |
| D8 | 그 EFS 배송비는 **KLOW 부담** — efs-billing 업로드에서 **미매칭으로 잡히지 않고**, **어떤 브랜드 청구서에도 들어가지 않는다** |
| D9 | **Retail price 는 바이어 공간 전체에서 숨긴다**(상세·카드·목록). 어드민 입력칸은 남긴다 |
| D10 | 어드민 주문 목록 유형에 **'바이어주문'** 추가 + 어드민 바이어 그룹에 **'바이어 주문'** 탭 신설 |

## 계획 세션이 정한 것 (사용자가 뒤집을 수 있다)

- **주문 1건 = 제품 1개.** 장바구니 없음(지운 박스 장바구니를 되살리지 않는다). 버튼 → 주문서 → 결제.
- **브랜드 정산 없음** — 결제금 전액 KLOW. 바이어 주문은 정산·브랜드 발송 대기·브랜드관 통계·CRM 연락처·소비자 주문 조회에 들어가면 안 된다(`Order.kind` 로 가른다 — 아래 G2).
- **브랜드에게 알리지 않는다** — 인디 제품도 KLOW 가 직접 산다(브랜드 스튜디오·알림톡 무변경).
- **배송지는 주문서에서 받는다** — `BuyerUser` 에 주소가 없다. 국가 기본값은 계정 국가, 바꿀 수 있다(7kg 요율이 있는 국가만).
- **메일**: 바이어 주문 확인 1통 + 운영팀 알림 1통(송장 발급 뒤 추적 메일은 스코프 밖 — 바이어는 `/track` 사용).
- **환불**: 송장 발급 전에는 어드민 상세에서 전액 환불(기존 `payment.refundOrder`). 발급 뒤 환불은 400(송장 취소 먼저).

## 스코프 밖

- 장바구니·여러 제품 묶음 주문 · 수량 선택

- 서버측 Retail price 은닉은 하지 않는다 — 화면에서만 뺀다(공개 API 응답의 `msrpUsdCents` 제거는 C 에서 판단)
