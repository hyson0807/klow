# buyer-platform — 바이어 공간 (klow.kr/ · 어드민 큐레이션)

해외 바이어(수입상·리테일러·살롱)가 `klow.kr/` 에 들어와 **KLOW 가 골라 올린 브랜드와 제품**을
카테고리·큐레이션 선반으로 둘러보고, 도매 구간가·인증·스펙을 확인한 뒤 **문의**를 남기는 공간.
디자인 정본은 워크스페이스의 [`KLOWBUYER/`](../../../KLOWBUYER/) 목업이다(Next 15 · 순수 CSS · 전부 mock).

**누가 채우나** — 브랜드가 아니라 **KLOW 관리자**가 klow_admin 에서 채운다. 브랜드를 고르고, 제품별
바이어용 정보(인증·구간가·스펙)를 넣고, 이미지를 바이어 공간 톤에 맞게 다시 세팅하고, 홈의 카테고리·
히어로·선반을 짠다. 브랜드 쪽(klow_brand)은 이 트랙에서 **무변경**이다.

## 결정 요약

### 1. URL — `klow.kr/` 가 바이어 홈, 하위는 `/shop/*` (2026-10-04 사용자 결정)

| 경로 | 화면 |
|---|---|
| `/` | 바이어 홈 (히어로 · Collection · 브랜드 로고월) |
| `/shop/brands/[slug]` | 바이어 브랜드 페이지 (`Brand.slug`) |
| `/shop/products/[id]` | 바이어 제품 상세 (`Product.id`) |

지금 `/` 는 `redirect('/shop')` 한 줄이고 `/shop` 은 **쓰이지 않는 소비자 마켓 목록**이다(사용자 판단).
구 `/shop`·`/shop/search`·`/shop/recommendations` 는 **제거**하고 하단 탭바의 shop 탭을 정리한다.
브랜드관 `/[brandSlug]` · 소비자 제품상세 `/product/[id]` · 장바구니·결제·`/my` 는 **그대로**다.

### 2. 도매 구간가는 바이어 공간 전용 테이블 (2026-10-04 사용자 결정)

기존 B2B 도매(`B2bProductTerm` + `B2bPriceBreak`, 브랜드가 직접 입력하는 `/[slug]/b2b` 링크)와 **섞지
않는다.** 그 값은 브랜드 소유이고, 어드민이 바이어 공간용으로 손대는 순간 브랜드의 자기 링크 가격이
덮인다. 바이어 공간 가격은 **USD 고정**(센트 정수)이다.

### 3. 홈은 디자인 전체 — 카테고리 탭+검색 · 히어로 · 큐레이션 선반 · 브랜드 로고월 (사용자 결정)

카테고리·히어로·선반은 **전부 어드민이 편집하는 데이터**다(디자인의 하드코딩 `SHELVES`·`CATEGORIES`
를 테이블로). 디자인 선반의 자동 규칙(공급률 밴드·소매가 밴드)은 옮기지 않고 **관리자가 제품을 골라
넣는 수동 선반**으로 단순화한다 — 필터 규칙을 만들면 그 규칙의 입력값(MSRP·공급률)을 전 제품에 다시
채워야 해서다.

### 4. 행동 버튼은 문의 폼 하나 (사용자 결정)

로그인·채팅·샘플박스·결제는 **나중**이다. 그동안 `Request a quote` · `Ask the brand team` ·
`Request a brand` 는 **디자인의 Request 드로어 하나**로 받는다 → 서버 저장(`BuyerInquiry`) + 운영팀
메일 + 어드민 문의 목록. `Sample 1 unit`·샘플박스 바·`Ask about this product`(채팅) 버튼은 **숨긴다.**

### 5. 노출 게이트 = 어드민 공개 토글 + 필수 완비 (서버가 판정)

공개 API 는 `BuyerBrand.published && BuyerProduct.published && 필수 완비` 인 것만 낸다.
필수 7: **카테고리 · 구간가 ≥1행 · About · Size · Made in · Ingredients · 이미지 ≥1장(원본 포함)**.
소비자 쪽 구독 게이트(`PUBLIC_PRODUCT_WHERE`)와 **무관**하다 — 이 공간의 게이트는 어드민 큐레이션이다.
단 브랜드 `status = withdrawn` 은 제외한다. 미완비여도 저장은 막지 않고 어드민이 "필수 n/7" 로 보여준다.

### 6. 이미지 — 비어 있으면 브랜드 원본을 따라가고, 세팅하면 덮는다

`BuyerProduct.images` 가 **빈 배열이면 원본(`Product.image` + `detailImages`)을 실시간으로 쓴다.**
관리자가 한 장이라도 세팅하면 그 배열이 정본이 된다. "원본 이미지로 되돌리기" = 배열 비우기.
처음 올리면 브랜드가 꾸민 이미지가 그대로 보이고(사용자 요구), 관리자가 바꾼 뒤엔 브랜드가 원본을
고쳐도 바이어 공간이 흔들리지 않는다. 브랜드 로고도 같은 규칙(`BuyerBrand.logoUrl` null = 원본 로고).

## 스코프 밖

로그인·가입 · 제품 채팅(AskProduct) · 샘플박스·체크아웃·결제 · 계정·주문 내역 · 바이어 리뷰 ·
Concierge(`/match`) · 다국어(영어 단일). 각각 디자인에 목업이 있지만 이번엔 만들지 않는다.
