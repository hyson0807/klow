# buyer-platform — 바이어 공간 (klow.kr/ · 어드민 큐레이션)

해외 바이어(수입상·리테일러·살롱)가 `klow.kr/` 에 들어와 **KLOW 가 골라 올린 브랜드와 제품**을
카테고리·큐레이션 선반으로 둘러보고, 도매 구간가·인증·스펙을 확인한 뒤 **문의**를 남기는 공간.
디자인 정본은 워크스페이스의 [`KLOWBUYER/`](../../../KLOWBUYER/) 목업이다(Next 15 · 순수 CSS · 전부 mock).

**누가 채우나** — 브랜드가 아니라 **KLOW 관리자**가 klow_admin 에서 채운다. 브랜드를 고르고, 제품별
바이어용 정보(인증·구간가·스펙)를 넣고, 이미지를 바이어 공간 톤에 맞게 다시 세팅하고, 홈의 카테고리·
히어로·선반을 짠다. 브랜드 쪽(klow_brand)은 이 트랙에서 **무변경**이다.

## 결정 요약

### 1. URL — `klow.kr/` 가 바이어 홈, 하위는 `/shop/*` (2026-10-04 사용자 결정)

| 경로 | 화면 |
|---|---|
| `/` | 바이어 홈 (히어로 · Collection · 브랜드 로고월) |
| `/shop/brands/[slug]` | 바이어 브랜드 페이지 (`Brand.slug`) |
| `/shop/products/[id]` | 바이어 제품 상세 (`Product.id`) |

지금 `/` 는 `redirect('/shop')` 한 줄이고 `/shop` 은 **쓰이지 않는 소비자 마켓 목록**이다(사용자 판단).
구 `/shop`·`/shop/search`·`/shop/recommendations` 는 **제거**하고 하단 탭바의 shop 탭을 정리한다.
브랜드관 `/[brandSlug]` · 소비자 제품상세 `/product/[id]` · 장바구니·결제·`/my` 는 **그대로**다.

### 2. 도매 구간가는 바이어 공간 전용 테이블 (2026-10-04 사용자 결정)

기존 B2B 도매(`B2bProductTerm` + `B2bPriceBreak`, 브랜드가 직접 입력하는 `/[slug]/b2b` 링크)와 **섞지
않는다.** 그 값은 브랜드 소유이고, 어드민이 바이어 공간용으로 손대는 순간 브랜드의 자기 링크 가격이
덮인다. 바이어 공간 가격은 **USD 고정**(센트 정수)이다.

### 3. 홈은 디자인 전체 — 카테고리 탭+검색 · 히어로 · 큐레이션 선반 · 브랜드 로고월 (사용자 결정)

카테고리·히어로·선반은 **전부 어드민이 편집하는 데이터**다(디자인의 하드코딩 `SHELVES`·`CATEGORIES`
를 테이블로). 디자인 선반의 자동 규칙(공급률 밴드·소매가 밴드)은 옮기지 않고 **관리자가 제품을 골라
넣는 수동 선반**으로 단순화한다 — 필터 규칙을 만들면 그 규칙의 입력값(MSRP·공급률)을 전 제품에 다시
채워야 해서다.

### 4. 행동 버튼은 문의 폼 하나 (사용자 결정)

로그인·채팅·샘플박스·결제는 **나중**이다. 그동안 `Request a quote` · `Ask the brand team` ·
`Request a brand` 는 **디자인의 Request 드로어 하나**로 받는다 → 서버 저장(`BuyerInquiry`) + 운영팀
메일 + 어드민 문의 목록. `Sample 1 unit`·샘플박스 바·`Ask about this product`(채팅) 버튼은 **숨긴다.**

### 5. 노출 게이트 = 어드민 공개 토글 + 필수 완비 (서버가 판정)

공개 API 는 `BuyerBrand.published && BuyerProduct.published && 필수 완비` 인 것만 낸다.
필수 7: **카테고리 · 구간가 ≥2행(1개 샘플가 + MOQ 구간) · About · Size · Made in · Ingredients · 이미지 ≥1장(원본 포함)**.
소비자 쪽 구독 게이트(`PUBLIC_PRODUCT_WHERE`)와 **무관**하다 — 이 공간의 게이트는 어드민 큐레이션이다.
**승인 브랜드(`Brand.status = approved`)의 승인 제품(`Product.status = approved`)만** 올릴 수 있고 노출된다
(2026-10-04 사용자 결정) — 어드민 후보 목록도 그것만 보여주고, 올린 뒤 브랜드가 탈퇴·반려 등으로 승인 상태를
벗어나면 공개 API 가 자동으로 거른다. 브랜드의 제품 가리기(`hidden`)·구독 해지는 소비자 판매의 문제라 보지 않는다 —
그건 어드민 공개 토글이 정한다.
`Brand.slug` 가 없는 브랜드는 바이어 브랜드 페이지 주소가 없어 노출할 수 없다 — 어드민에 "slug 없음" 으로 띄운다. 미완비여도 저장은 막지 않고 어드민이 "필수 n/7" 로 보여준다.

### 6. 이미지 — 비어 있으면 브랜드 원본을 따라가고, 세팅하면 덮는다

`BuyerProduct.images` 가 **빈 배열이면 원본 대표사진 1장(`Product.image`, 비었으면 `detailImages` 의 첫 사진)을
실시간으로 쓴다.** `detailImages` 는 소비자 PDP 본문용 상세컷(세로로 긴 한글 상세페이지·동영상 포함)이라 바이어
갤러리에 통째로 넣지 않는다(2026-10-04 사용자 결정) — 어드민 이미지 편집기에서 **"원본 상세컷에서 골라 넣기"** 로
한 장씩 가져올 수는 있다.
관리자가 한 장이라도 세팅하면 그 배열이 정본이 된다. "원본 이미지로 되돌리기" = 배열 비우기.
처음 올리면 브랜드가 꾸민 이미지가 그대로 보이고(사용자 요구), 관리자가 바꾼 뒤엔 브랜드가 원본을
고쳐도 바이어 공간이 흔들리지 않는다. 브랜드 로고도 같은 규칙(`BuyerBrand.logoUrl` null = 원본 로고).

### 7. 브랜드관 손님은 브랜드관에 머문다 — `/shop`·`/` 로 새는 경로를 막는다 (2026-10-04 사용자 결정)

**지금도 버그다.** 브랜드관(`/[brandSlug]`)·브랜드 링크로 들어온 소비자가 뒤로가기·빈 카트·빈 주문내역·
하단 탭바에서 **`/shop`(KLOW 마켓 = 경쟁 브랜드 목록)으로 떨어진다.** 이 트랙이 `/shop` 을 지우고 `/` 를
바이어 홈으로 바꾸면 같은 경로가 이번엔 **바이어 공간**으로 새므로, 폴백을 `/` 로 바꾸는 것으로는 안 된다.

규칙: **소비자 화면의 어떤 폴백·CTA·탭도 `/shop` 이나 `/` 를 가리키지 않는다.** 돌아갈 곳은 항상
**그 손님의 브랜드관**이고, 우선순위는 `현장 복귀 URL → 화면이 아는 브랜드(?brand=·제품의 브랜드·카트의
브랜드) → 이 탭에서 마지막으로 본 브랜드관(sessionStorage breadcrumb `klow-brand-return`)` 이다.
셋 다 없으면 **버튼을 숨긴다**(엉뚱한 곳으로 보내느니 없는 게 낫다). 이 판단은 `lib/brandReturn.ts` 의
헬퍼 하나가 하고 호출부는 그걸 부른다. 대상 목록은 `implementation-plan.md §3 3단계 ①`.

### 8. 디자인 문구는 그대로, 문의 수신은 KLOW 운영팀만 (2026-10-04 사용자 결정)

히어로("Samples at wholesale price. Even just one unit.")·기둥(1 unit / 5 SKUs)·Sample program 섹션·구간가 첫 행
`sample` 은 **디자인 문구 그대로** 둔다. 샘플 요청은 그동안 문의 폼으로 받는다(샘플 버튼 자체는 결정 4대로 숨김).
문의는 **KLOW 운영팀만** 받는다 — 브랜드에 사본을 보내지 않고 klow_brand 도 무변경이다.

### 9. MOQ 는 구간가 표가 정본, 카드 가격은 MOQ 구간가 (2026-10-04 사용자 결정)

구간가 표의 **첫 행은 항상 `1개 → 샘플가`**, **둘째 행의 시작 수량이 그 제품의 MOQ** 다. 제품·브랜드에 MOQ 칸을
따로 두지 않는다 — 세 군데 두면 "MOQ 48 인데 구간은 1/100/300" 같은 모순이 저장된다. 브랜드 페이지의
`Opening order` 는 그 브랜드 노출 제품 MOQ 의 **최솟값**, `Avg. retail multiple` 은 노출 제품 `MSRP ÷ MOQ 구간가`
평균으로 **서버가 계산**한다(입력 칸 없음). 카드·브랜드 패널·선반에 보이는 도매가 한 개 = **MOQ 구간 가격**이고
High margin 선반 태그의 공급률도 이 값 ÷ MSRP 다.
