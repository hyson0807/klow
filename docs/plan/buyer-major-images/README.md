# buyer-major-images — 메이저 제품 이미지 AI 일괄 리터치 (어드민 제작 페이지)

목표: 바이어 공간 메이저 제품 이미지를 **하나의 프롬프트로 통일된 스튜디오 컷**(4:5 · 크림 배경 · 홍보 문구 제거)으로 바꾼다.
어드민에서 **브랜드를 고르고 → 테스트 1개 → 결과 확인 → 그 브랜드 전 제품 생성 → 검토 → 일괄 적용**한다.

배경(2026-10-28~31 대화): 올리브영에서 메이저 50개 브랜드·579개 제품·이미지 2,146장을 넣었다(스킬
`oliveyoung-major-import`). 원본은 1000×1000 정사각형 상세 썸네일이라 홍보 배지·물방울·문구가 섞이고, 바이어 공간의
주 카드(`.card__frame`)는 **4:5** 라 좌우가 잘린다.

## 결정 (계획 시점)

| # | 결정 | 근거 |
|---|---|---|
| D1 | **OpenAI 이미지 편집 API**(구독제 아님). 서버 `openai` SDK · `OPENAI_API_KEY` 재사용 | 수백 장 일괄·결과를 R2/DB 로 되돌려 넣는 자동화가 필요. 구독(ChatGPT)은 수작업이고 자동화가 약관 위반 |
| D2 | **출력 = 4:5 · 1024×1280 · WebP(q≈80) · 장당 ≤ 250KB** | 바이어 공간은 `<img>` 원본을 그대로 내려받는다(`next/image` 없음). API 기본 PNG(1.5~3MB)를 그대로 올리면 목록 1페이지가 50~100MB. gpt-image 는 4:5 크기를 직접 못 낸다 → 2:3(1024×1536) 받고 `sharp` 로 크림 배경 패딩/크롭 |
| D3 | **원본은 버리지 않는다** — 적용 시 기존 `images` 를 백업, 제품·브랜드 단위로 되돌리기 | 생성 모델은 라벨·로고 글자를 조금씩 바꿔 그린다(지시해도 보장 없음). 판매 화면의 오표시 위험 |
| D4 | **생성과 적용을 분리** — 생성 결과는 초안(draft)으로 쌓이고, 사람이 보고 **적용 버튼**을 눌러야 `images` 가 바뀐다 | 비용을 쓴 결과가 자동으로 운영 화면에 나가지 않게 |
| D5 | 생성은 **서버 백그라운드 + 폴링** — HTTP 요청은 즉시 반환, 어드민은 상태를 주기 조회 | 장당 30~90초 · 브랜드 15장이면 수 분. 요청 타임아웃 회피 |
| D6 | 프롬프트는 **서버 상수 + 버전**(초안에 버전 기록). 어드민 편집 UI 는 이번 범위 밖 | 프롬프트가 바뀌면 이전 결과와 섞이지 않게 추적. 편집 UI 는 필요해지면 후속 |
| D7 | **어드민에 OpenAI 비용·예산 표시** (2026-10-31 사용자 결정) — ① 이번 작업 비용(생성마다 응답 `usage` 토큰 → 비용을 초안에 기록, 브랜드·전체 합산, 실시간) ② OpenAI 조직 사용액(Costs API `/v1/organization/costs`, **Admin 키** `OPENAI_ADMIN_KEY` — 사용자가 발급) ③ 남은 예산 근사 = 어드민이 입력한 충전액 − 조직 누적 사용액 | OpenAI 는 **잔액 조회 공식 API 가 없다**. 생성용 `OPENAI_API_KEY` 는 `sk-proj-` 프로젝트 키라 조직 사용액 API 권한이 없다 → Admin 키가 별도로 필요. 정확한 잔액의 정본은 OpenAI Billing 화면 |

### ⚠️ 착수 시 사용자에게 확인할 것 (정책 공백 — 계획서에 추측으로 박지 않음)

1. **어느 이미지를 바꾸나** — (a) 제품당 대표 1장(`images[0]`)만 생성해 맨 앞에 두고 나머지 원본 유지 / (b) 대표 1장 생성으로 `images` 전체 교체 / (c) 모든 이미지 생성(비용 ×3.7). **계획 기본값은 (a)**.
2. **품질·모델** — `gpt-image-1` high 기준 장당 약 $0.25~0.30(2026-10 기준 추정 — 착수 시 OpenAI 가격표·신모델 확인). 대표 1장×579 ≈ $170~250.
3. **브랜드당 전체 생성 전 확인창의 예상 비용 표시**를 넣을지(기본: 넣는다 — 제품 수 × 단가 + 남은 예산 근사).

⚠️ 사용자 준비물: **OpenAI Admin 키**(대시보드 → Settings → Organization → Admin keys, `sk-admin-…`)를 로컬 `klow_server/.env`·staging·운영 Railway 에 `OPENAI_ADMIN_KEY` 로. 없으면 ②·③ 칸만 "Admin 키 없음" 으로 숨기고 나머지는 동작.

## 비용·시간 (참고 — 2026-10-31 운영 실측 기준 데이터량)

- 운영 메이저: 브랜드 50 · 제품 579 · 이미지 2,146(제품당 1~5장)
- 대표 1장 high: 약 $170~250 + 재생성 20~30% · 동시 3~5장이면 브랜드당 수 분, 전체 1~2시간
- R2 저장비 무시 가능(0.4GB 수준) · R2 는 egress 무료
